關鍵功能：搜尋式下拉選單

98 筆客戶資料如果用傳統 select 下拉選單，難以使用。系統改用關鍵字搜尋式下拉，輸入即時過濾，大幅提升資料選取效率。

運作流程

  1. 點擊客戶輸入框，展開下拉候選清單
  2. 輸入關鍵字，程式即時以 includes() 對姓名/電話過濾
  3. 點擊候選項目，寫入 hidden input（customer_id）
  4. 點擊外部，自動關閉下拉（useRef + mousedown 事件偵測）
  5. 編輯模式時，以 customer_id 反查客戶名稱自動填入

技術要點

  • useRef 偵測點擊外面：ref.current.contains(e.target)
  • filteredCustomers = 姓名或電話 contains 搜尋文字
  • hidden input 實際傳送 id，input 只顯示名稱

關鍵程式碼

關鍵功能：Rich Text 編輯器

維修問題描述、維修過程、客戶備註都需要格式化文字。系統使用 @tiptap/react 取代 react-quill，完整支援 React 19。

為什麼放棄 react-quill？

  • react-quill 只支援到 React 18
  • React 19 移除了 findDOMNode API
  • 升級 React 19 → react-quill 直接空白頁
  • @tiptap 是模組化架構，按需要選擇擴充
  • 輸出 HTML，與 Tailwind prose 完美整合

關鍵功能：出貨單 PDF 列印

出貨單要在點陣印表機（Epson LQ 系列）上穩定輸出，採用 html2canvas + jsPDF 截圖轉 PDF，完全繞過瀏覽器列印引擎的不穩定性。

版面規格（中一刀紙張）

紙張尺寸：9.5" × 5.5"（寬 × 高） 方向：直印（Portrait） 印表機設定：Width=950, Height=550（1/100"） jsPDF 關鍵（繞過 bug）： jsPDF('landscape', 'pt', format:[684, 396]) → MediaBox [0 0 684 396] = 9.5×5.5 inch ✓ html2canvas 截圖後，逆時針旋轉 90° 再放進 PDF

技術挑戰

  • jsPDF bug：portrait + format:[w,h] 會交換寬高，用 landscape + 旋轉解決
  • 瀏覽器不一致：@page CSS 各瀏覽器解讀不同，直接生成 PDF 繞過
  • CSS 寬度：必須與 @page size 完全一致，否則內容被壓縮

PDF 生成流程

  1. 出貨單詳情頁，點「列印出貨單」→ 新分頁開啟 /shipments/{id}/print
  2. 呈現完整版面（公司抬頭、客戶資料、商品明細、注意事項、簽收欄）
  3. 點「下載 PDF」→ html2canvas 以 9.5×5.5in 尺寸截圖
  4. Canvas 逆時針旋轉 90°，以 landscape jsPDF 嵌入圖片
  5. 觸發下載，檔名：出貨單_{單號}.pdf

出貨單內容對照

  • 公司抬頭列（名稱、地址、電話/傳真、貨單號碼）
  • 大標題「出　貨　單」（邊框、letter-spacing）
  • 收費標準（診斷費/車馬費/系統重灌等）
  • 注意事項（版權聲明、保固說明、三日通知期限）
  • 簽收欄（工程師 / 客戶簽名 / 日期）

開發過程中的關鍵除錯經驗

從 SQLAlchemy ORM 改走 REST API、克服雲端主機網路限制、PDF 列印相容性問題——每一個障礙都是學習的機會。

🚫 雲端主機無法直連資料庫

問題：Render 無法直接連線 Supabase PostgreSQL port 5432，被防火牆封鎖。
解決：不走 port 5432，改走 HTTPS 443 的 REST API（PostgREST），完全繞過網路限制。放棄 SQLAlchemy ORM，改用 httpx 直接發 HTTP 請求。

🐛 Dashboard 三個 Bug 同時爆炸

問題：eq. 雙重前綴、in() 逗號被 URL 編碼、Decimal 序列化失敗，三個問題同時存在。
解決：逐一隔離：filter 加 operator prefix pass-through、in() 拆成兩個串聯查詢、移除 response_model 直接回 dict。

📄 jsPDF 紙張尺寸 Bug

問題：直覺上 format:[612,396] portrait 應該是 8.5×5.5，實際輸出是 5.5×8.5（寬高交換）。
解決：用 landscape 模式建立文件，截圖逆時針旋轉 90° 放進去，視覺上變成正確的 9.5×5.5 中一刀。

⚛️ React 19 + react-quill 不相容

問題：react-quill 使用已被 React 19 移除的 findDOMNode，會造成頁面空白。
解決：全面改用 @tiptap/react，模組化擴充設計，更穩定且未來易於升級。

核心心法： 雲端環境和本地環境差異很大，很多「在本地正常」的程式在雲端會因為網路、檔案系統、依賴版本不同而失敗。逐一隔離問題、一次只改一個變數——這是雲端除錯的基本原則。
